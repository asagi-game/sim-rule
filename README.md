# 編成動画におけるシミュレーションルール

## キャラのビルド
### キャラの凸
- 星5は注釈がない限り全て無凸(開拓者は完凸)
- 星4は全て完凸

### 光円錐の凸
- 星5は無凸、星4は完凸

### アタッカーのビルド
- モチーフ・最適な遺物

### 調和・記憶・愉悦
- 御空以外参加
  - 爻光以外の愉悦は愉悦アタッカー時のみ参加
- 光円錐
  - 限定キャラはモチーフ固定
  - その他は星4光円錐で比較して最も良かったもの

### 虚無
- ヴェルト・セイレンス・サフェル・真停雲・銀狼、ブラックスワン、椒丘、カフカ、ペラ、桂乃芬
  - サンポ、ルカは持続ダメージキャラのみ参加
- 光円錐
  - 限定キャラはモチーフ(銀狼はサフェルモチーフ)
  - その他は星4光円錐で比較して最も良かったもの

### 耐久
・騰荒・ヒアンシー・フォフォ、符玄、ギャラガー、霊砂
- 光円錐
  - 限定キャラはモチーフ(銀狼はサフェルモチーフ)
  - その他は星4光円錐で比較して最も良かったもの
- 羅刹はシミュレーション上、ギャラガーとほぼ変わらないので不参加

## 組み合わせルール
- 1人目：メインアタッカー
- 2人目：調和・虚無・記憶・愉悦(サポーター枠)から
- 3人目：上記＋サブアタッカーから
- 4人目：耐久から
同じ編成で、同じ光円錐の使用は不可
- 光円錐を含めた全パターンをシミュレーション
- 編成メンバーが同じものは、最も数値が良かったものだけを記録

## シミュレーションシナリオ
- 通常
  - 2体のボス(靭性140)と指定ラウンドの戦闘を1ウェーブ行う
  - 敵の弱点はメインアタッカーの属性
  - 行動値450(ウェーブ切り替えナシ)

## 遺物について
- 基本的にキャラクターに適しているものを選択
  - 編成によって、サルソット、競技場、グラモスの強さが変わるが、クリアラウンドには殆ど影響がないので、計算量削減のため変更しない
- メインアタッカーはキャラによっては速度靴と(HP/攻撃/防御)靴の2パターンを検証
　- ステータスの最適化はそこまで細かく行っていない

## サブステータスについて
- 全てのサブステータスに2回ずつ割り振り
- 任意のステータスに合計24回割り振り
- 同じステータスは最大12回まで(メインステータスと同じものは10回まで)
